# OTB15：遅れて届く誤差が共有振幅記憶を書き換え、未見の組合せへのT7応答を変える

2026-11-04。探索的な数値機構実験。先行pilotでパラメータを選び、別seedのmain取得前に設計・設定・実行コード・監査コード・元の式をローカルSHA256で固定した。第三者への事前登録ではない。

**固定したT7核と双安定振幅記憶に、短期の経路履歴 `e` と誤差累積 `s` を接続した。与えた特徴の区切りの中では、遅延した観測結果によって共有対応を学習し、片方の操作の規則が反転した後に、その共有記憶を更新できた。** 未見の完全特徴組合せへの予測は、別8seedすべてで学習後8/8、保持後8/8、反転後8/8だった。

**非振動の数値記憶対照と、直近観測を保存する小さな数値表も同じ課題を解く。振動子の性能・効率優位、特徴や意味の自動獲得、スケーリング則は示していない。**

## 主結果

各条件は8seed。1seedあたり4個の未見プロファイル×2操作＝8問を評価した。初期の対応規則は4通りの反転ビットの組合せを各2seedで試している。64問を64個の独立した未知世界と数えない。

通常条件では、学習後80,000 native stepを入力結果なしで保持しても64/64だった。操作0だけを反転させた後は、変わった操作0が32/32、変えていない操作1も32/32。保存状態の事後集計では、操作0の32セルはすべて反対の振幅帯へ移り、操作1の32セルはすべて元の帯に残った。状態の数値が完全に同じという意味ではなく、低振幅／高振幅の記憶帯が保たれたという意味である。

学習後の記憶から作業T7への伝達を切る診断では、全条件で64/64が保留した。通常条件の最終回答は、保存した教師ラベルの直接参照ではなく、記憶振幅に依存する入力を受けた作業T7の発火から決まる。

## 何を学習し、何を与えたか

入力は3個の二値特徴 `x=(x0,x1,x2)` と操作 `a∈{0,1}`。**操作0は特徴0、操作1は特徴1を参照する配線を、設計者が与える。** 学習器には、各操作で特徴値0/1がどちらの結果へ対応するかを教えない。環境は `y = x[a] XOR flip[a]` で結果を返す。

訓練プロファイルは `000,011,101,110`。試験は `001,010,100,111`。全体として初めての特徴組合せへ、共通の特徴値の対応を再利用する試験である。訓練・試験とも、参照される個々の特徴値自体は既知であり、**特徴の関連性、未知の概念、役割、因果構造を発見した試験ではない。** 転用できるような因数分解を入力符号と配線に与えている。

初回は4プロファイル×2操作を2周し、16回の結果を観測する。その後、80,000 step保持し、操作0の対応だけを環境側で反転する。反転後は4プロファイル×操作0を2周、8回観測する。反転フラグや正しい規則そのものを学習器へは渡さない。与えるのは、それぞれの問い合わせ後に観測した結果1個だけである。

作業T7は試行間でも状態を引き継ぐ。ただし、各問い合わせ前の1,024 stepと待機中には、`m` を−1.2へ近づける固定の準備入力を与える。位相・不応期を直接リセットしないことと、外部準備入力がないことは別である。試験プローブは同じ境界状態のコピーで実施し、元の学習経路を変更しない。

## 固定した学習則

8セルは「操作2×参照特徴値2×結果2」に対応する。各セルはT7の `m, phase, cd` と、OTB2の相方の `u, psi` を持つ。T7の式と相方の双安定多項式は変えず、相方の傾き入力へ新しい項を加えた。

1. 問い合わせの入力用T7が発火すると、選択された操作・特徴値の2結果セルの `e` を1にする。他の時間は `e` を減衰させる。
2. T7の予測を読んだ後、一定時間待って実際の結果を受け取る。
3. `delta = one_hot(観測結果) − p(T7出力)` を求める。片方だけ発火なら `p` はその結果のone-hot、両方／無発火なら `(0.5,0.5)` とする。
4. `s` が `e*delta` を漏れながら積分し、相方の振幅への符号付き入力になる。

```text
e <- exp(-1/tau_e) * e          # 該当する入力発火時のみ e <- 1
s <- s + (e*delta - s)/tau_s
h  = 0.1*tanh((m-MC)/SCALE) + alpha*s + noise
du/dt = 2*NU*u*((u-2) - (u-2)^3 + h)
```

`e` は最近使った経路の履歴、`s` はその履歴に届いた誤差の累積であり、別の状態である。主設定は `alpha=6, tau_e=6000, tau_s=1000`。予測窓4,096 step、予測終了後の追加待ち1,000 step、結果を与える学習窓8,000 stepとした。`e` は待機・学習窓の間も減衰する。結果差は全セルの対応する結果座標へ届き、最近の履歴が残ったセルほど書き換わる。

これは教師ありの誤差入力を使う設計された局所則である。`e,s` は非振動の補助状態であり、その実機回路を作ってはいない。誤差の算出、入力の宛先、準備入力、結果の提示時間、one-hotと保留の読み方は外部にある。原理としては既知の三因子学習に近く、局所更新の式自体を新発明とは主張しない。

## 同じ状態からの符号分岐

通常条件seed 24001の最初の反転経験について、予測直後の同じ状態から3種類の更新を分岐させた。この診断の結果は学習器へ返さない。

| その1経験の更新 | 反転した操作0の未見4問 | 未反転の操作1の未見4問 |
|---|---:|---:|
| 通常の誤差 | 正答2、誤答2 | 正答4 |

| 誤差0 | 正答0、誤答4 | 正答4 |

この経験で観測した特徴値に対応する共有記憶が変わり、同じ値を含む未見の2プロファイルへの予測が改善した。もう一方の値はまだ観測していないため、誤った旧規則のままである。これは1箇所・1状態の有限の更新方向診断であり、全体の勾配や深い信用割当が正しいという証明ではない。

## 成立範囲と失敗

遅延の値は、予測窓終了後の追加待ち時間である。履歴を設定する入力発火から結果までの総時間は、それより長い。追加待ち1,000 stepでは学習できた一方、6,000以上の固定条件では全て保留した。振幅が変化しても、高振幅の記憶帯へ達するだけの入力と時間が足りない場合がある。待ち時間のどこに境界があるかを細かく特定した実験ではない。

`alpha=0.2`、雑音なしでは、`|e|,|delta|,|s|≤1` と保持項から `|h|≤0.3`。双安定多項式のfold閾値 `2/(3*sqrt(3))≈0.3849` より小さく、低い側から高い側への切替が起きないという理論的な制約と整合する。ただし一般には、閾値を一瞬超えただけで有限時間内に切り替わるとは限らない。

pilotでは18設定×2seedを試した。短い履歴では学習しない設定があり、長い履歴と強い入力の組合せでは、反転後6/8にとどまる設定もあった。これらも `pilot/pilot_20261104_233446.json` に残している。mainの係数はpilot成功を見て選んだもので、理論だけで予言した値ではない。

雑音条件が通過したのは、振幅式のtiltに毎step独立な標準偏差0.08の正規雑音を加えた範囲である。現実の素子ばらつき、色付き雑音、ドリフト、位相読み出し誤差、観測ラベル誤りへの耐性を意味しない。

## 数値対照・費用・スケールに関する判断

非振動の機構対照では `u,e,s` の更新を残し、記憶側のT7からのフィードバックを除き、振幅帯を直接読む。入力発火の符号器は共通である。記憶側フィードバックと出力の読み方を同時に変更しているため、「振動だけ」を消した一要因の対照ではない。この対照も全問正答し、現在の課題では振動子方式に固有の学習性能を示せていない。

さらに、同じ操作・特徴値で最後に見た結果を保存する4エントリの数値表で全問解ける。これは強い比較対象というより、与えた因数分解の下では課題自体が小さいことを明確にする基準である。実装上は4個のint64で32 byte。T7方式の動的配列は次の通りで、544 byteである。

| 状態 | 数 |
|---|---:|
| T7＋相方の記憶セル | 8組、計40スカラー |
| 非振動の `e,s` | 16スカラー |
| 作業T7の `m,phase,cd,previous` | 3個、計12スカラー |
| 合計 | 68個のfloat64、544 byte |

入力・索引・外部制御・教師・乱数・保存軌跡・Pythonや一時配列はこの544 byteに含まない。数値対照で実際に更新する記憶は `u,e,s` の24スカラーで、さらに入力符号器と外部制御がある。通常の学習経路は保持を含め394,304 native step。main全体の経過時間約38.6秒には診断コピーと保存等を含み、ハードウェア速度・電力比較には使えない。

通常条件の全stepで、振幅は約0.525〜3.573に収まり、全状態が有限で `u>0` だった。8seed以外の広い初期条件や任意の入力強度の安定性は証明していない。

**この試験は規模を増やす実験ではない。** 局所履歴によって更新箇所を限定できたが、より多くの関係や長い推論で学習が成立すること、配線・時間・記憶費用が有利に伸びることは別途示す必要がある。

## 研究として言えること

> 既知の特徴配線を持つ小さな反応予測系で、T7の予測誤差が短期履歴と誤差累積を介して共有振幅記憶を書き換え、その後のT7の運動を変える機構を確認した。規則反転後の訂正は、観測した個体専用の上書きではなく、同じ特徴値を持つ未見プロファイルにも及んだ。成立には入力強度と履歴寿命の条件があり、数値記憶対照に対する優位はまだない。

これはOTB14の「対象別に観測を追加する」段階から、**与えられた因数分解の中で共有対応自体を経験から更新する**段階への限定的な前進である。一般の例外について、どこまで共有規則を修正すべきかを判断する仕組みはない。対象固有の例外を今回の更新則へ与えると、同じ特徴値を持つ別対象へ誤りを広げる可能性が残る。

三因子学習と活動履歴の先行例：[Izhikevich（2007）](https://izhikevich.org/publications/dastdp.htm)、[Legensteinら（2008）](https://pmc.ncbi.nlm.nih.gov/articles/PMC2543108/)。計算と記憶の振動自由度を組み合わせる近接例：[de Bos・Serra-Garcia（2026）](https://www.nature.com/articles/s44455-025-00015-4)。それらとの差分、新規性、実装上の利点を確定した報告ではない。
