## 記憶に依存して運動が変わる振動子ネットワーク

**記憶は、振動子の運動、接続による計算、そして学習をどう変えるのか。**

研究の出発点は、内部記憶が自身の運動を変える振動子を選び、まずその単体の性質を理解することです。その発火を別の振動子への入力として接続したとき、経験の保持・計算・更新・共同利用がどこまで成立するかを調べています。

1. **単体の力学**：内部状態mが位相の進みを変え、入力や発火がmを変える。入力応答・発火・不応期との関係を理解する。
2. **接続と計算**：記憶を含む応答を、受信側が使える信号として受け取り、計算や準備選択につなぐ。
3. **継続計算と学習**：状態を引き継いで計算し、経験で更新し、変更のない記憶への干渉を抑える。
4. **経験の共同利用**：異なる系に保持された経験を接続中に利用する。矛盾処理や受け手の学習は今後の課題。

公開版では、この研究全体の入口と、最初の再現可能な実験OTB21を分けています。E7-D・OTB15・OTB22は一次報告を同梱していますが、それぞれの実験一式の公開・再現とは区別しています。

OTB21では、短い問い合わせ条件での旧関係保持が、通常更新・固定待機で64/128、状態に基づく待機で128/128になりました。新関係は全方式で学習できています。ただし時間費用が増え、最適な長い固定待機への優位は示していません。

T7の内部状態mと、後期OTBで追加した双安定の相方、活動履歴e、誤差蓄積sは役割が異なります。すべてが裸のT7だけで成立した成果ではありません。一般知能、意味の自動獲得、通常方式への効率優位は未実証です。
