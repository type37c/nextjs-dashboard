# 学習の準備可能性

過去の問い合わせで残った活動履歴が、次に届いた正しい教師信号を別の記憶にも流してしまう。その干渉を、次の問い合わせ前の待機条件で抑えられるかを調べた小さな数値実験です。

OTB21の1,152条件では、新関係は全方式で学習できました。短い問い合わせ条件での旧関係保持は、通常更新・固定4,096ステップ待機が64/128、状態に基づく待機が128/128。ただし所要時間は増えます。最適な長い固定待機を上回ることは示していません。

公開版は元の実験コード、学習済み入力状態、保存データ、監査と英語の説明をまとめています。再現コマンドと共同研究の候補はルートREADMEを参照してください。未ラベルの履歴と教師誤差の干渉という限定課題であり、意味理解や汎用AIの完成を主張するものではありません。
