## 文献照合で明確にしたこと

ALIF、GRU、Mamba、NTM、RAGなどは履歴の保持・選択的更新・アクセスを既に扱う。
Dambreらは許される読み出しを通じて記憶と計算を結びつけている。
したがって「主流は履歴を扱わない」「適応は記憶ではない」という対立は置かない。
e-propの時間的credit assignmentとOTB21の待機判断も同じ機能として扱わない。

e-propは2020年のNature Communications掲載版の題名・著者・内容を確認した。
2019年初期プレプリントを掲載版の書誌として転記しない。EWC等の6本は確認した
arXiv版を引用する。確認箇所・短い抜粋・取得記録ハッシュは別ファイルに残す。
全文献・全版を精読した、独自性を網羅的に証明した、とは書かない。
