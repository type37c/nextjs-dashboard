# 履歴寄与：解析を取得前に固定した新cohort評価

2026-11-06。**主差は正だが、事前に定めた「95%区間の下限が3ポイントを超える」基準は未達。**

通常T7の全7回成功率は56.89%、過去成分の位相寄与を単発除去したT7は52.81%。同予算で学習済みの読み出しを凍結した主比較は **+4.0820ポイント、95%区間 [+2.9883, +5.1563]** だった。下限を丸めて3ポイント超と判定しない。分類は `positive_difference_minimum_effect_unestablished`。

正の差を支持する結果と、最小重要差を超えることの確証を区別する。今回「3ポイント超の優位を確立した」とは書かない。一方、無効果・同等性・反対方向が示されたわけでもない。基準を変更した再判定や、基準を通すための追加取得は行っていない。

## 実験の位置づけ

pilotコミット `9bd3897` の結果を見て、設計 `bf27bf3` を作成した。取得・解析・監査コードを `2e69572`、取得前ハッシュを `1bb275e` に保存した後に新しいcohortを生成した。取得前コード凍結時刻は2026-11-06 04:48:53 UTC。

これは**外部事前登録を行っていない、ローカルで取得前に解析を固定した新入力評価**である。Gitのローカル履歴だけを第三者が時点を保証した登録とは扱わない。pilotの評価群を未使用群と呼び直してはいない。

- 固定5回路（200–204）、保持時間512・16384、各回路128履歴群。
- 1群4行、両保持時間と条件間で対応。主解析の再抽出単位は計640履歴群。
- 各セル5,120チェーン。B0／B2単発 × 読み出し／固定準備の4セル、計20,480チェーン。
- 各チェーンの介入後7計算がすべて成功したかを主評価。
- B0／B2ごとにpilotで同予算で学習した、計10個の読み出しを凍結使用。今回の評価群では再学習しない。
- 固定準備は全回路・両基板で同じ候補1。候補、時間予算、参照値、介入タイミングは設計どおり。
- 全予定群を1回取得。取得処理224.91秒。準備・解析・監査を含む総作業時間や実機の計算効率ではない。

## 監査結果と手順上の差分

- モデル、pilotの数値実装、取得前に固定した取得・解析・監査コードのSHA256一致を確認。
- 既存記録3,018テキストファイルの整数seed／近接base検査で既知の衝突なし。すべての遠隔ブランチ・導出seedを調べたものではない。
- 新640履歴群と、pilot訓練・pilot評価・既存E7-D確証の計1,080群の履歴トークン照合で重複0。履歴トークンは初期位相・書込時間・書込係数・新規入力係数を小数12桁で比較する。全過去実験に対する独立性証明ではない。
- 全40評価ファイルで共通入力・共通介入前状態・有限値・固定候補・B2介入境界・観測shadow再構成を検査。保存した実入力候補予測は、選択後の実現成否と全件一致。
- 取得前に指定した96軌道を別スカラー実装で再計算。発火数・成否・終状態が一致し、最大絶対誤差0。
- shadow再構成誤差は0だが、コピー振動子とPのmには最大約0.6の差を記録した。元の1step補正遅延等を含む差であり、読み出し装置が常時完全コピーという主張ではない。
- 取得エラーや結果を見た後の条件変更はなく、予定数を1回取得した。scikit-learnの保存版と実行版の差による既知の警告はログに保存。元モデルの明示係数推論とpilotでの元実装／保存結果との一致検査を引き継ぐ。

**手順差分：入力ファイルは各シミュレーション前に保存したが、その生成時点で個別SHA256を保存する処理は入っていなかった。** 入力生成コード・seedは取得前に固定し、個別入力ファイルのハッシュは取得後のartifact manifestに収録した。設計書の「生成時点でハッシュ保存」を完全に実施したとは記載しない。

数値監査は同一作業内の別実装検査であり、外部研究者による独立追試ではない。

## 論文に書ける結論

> In a fresh-cohort evaluation with the analysis fixed before acquisition, normal T7 achieved 56.89% seven-step success versus 52.81% after removing the pre-boundary memory contribution to phase evolution. The difference was +4.08 percentage points (95% paired group bootstrap interval: +2.988 to +5.156). This supported a positive conditional difference but did not meet the prespecified criterion that the lower bound exceed three percentage points. One of five fixed circuits showed the opposite direction. Under fixed preparation, the intervention instead improved success, preserving the policy-dependent reversal observed in the pilot.

基板別の再学習を何度繰り返しても同じという訓練頑健性、新回路への一般化、履歴内容と動作点の完全な分離は示していない。結果は既存5回路・10個の特定の学習済み方策・今回の入力分布に条件づける。

C3の移植救済、OTB型の更新と保持、LIF／ALIFへの優位、実機効率、知能の種の同定は今回検証していない。pilotでの未達・不利な証拠を消さず、論文では探索結果と本評価を別に記載する。

今回の結論は、**「正の主差は別cohortでも得たが、最小効果の確証基準は満たさなかった。一方、履歴の効果が準備方策と入力条件で逆転することは引き続き観測された」**である。
