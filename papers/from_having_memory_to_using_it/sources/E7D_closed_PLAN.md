# E7-D 閉ループ 探索計画 v0.1（凍結してから一度だけ実行）：記憶の写しの読み出しで、連続計算の準備を回路の中で選ぶ

**状態：**理論研究側の提言（「現在のE7-Dを凍結して閉ループで検証する。結果を見てから閾値や重みを変えた評価は、確証として扱わない」）に従い、凍結してから一度だけ実行する。
- 評価cohortでは、まだ何も実行していない。
- 実現可能性の確認は、E4-Aの訓練cohortだけで行った（`feasibility.py`）。

**順序：**
1. 凍結（`--freeze`）。
2. 較正（`--calibrate`、訓練cohortのみ）。
3. 評価を一度だけ実行する（`--evaluate`）。
4. 独立監査（`verify_e7dc.py`）。
5. 報告とPR。

失敗しても、閾値・重み・構成・判定を事後に変えない。

## 1. 問い

> E7-Dの読み出し（記憶の写しへの可逆な蹴り → 線形の重み）で準備を選ぶと、リセットなしの8回の連続計算で、それまでの回路の判断器より良くなるか。同じ二候補を外部の影で選ぶ方式に、どこまで近づくか。

**E7-Dの判断器（凍結）：**
- **素子：**128個の記憶の写しの読み出し素子（β = 0 のT7、記憶はPの記憶に一致）。
- **閾値：**回路ごとに、訓練状態でのPの記憶の分位点に置く。
- **蹴り：**計算の窓の128ステップ目に、可逆な蹴りを一度だけ与える。
- **素子の数：**K = 16 または 64 を、均等に選ぶ。
- **読み出し：**線形の重み。重みは、観測できるAの符号と、「蹴りの後にPが発火したか、それがいつか」の4区分で切り替える。
- **判断：**閾値の素子（z > 0 なら v）で決める。

**学習：**読み出しの重みは、訓練cohortのRANDOMの方策の状態（群0〜63、保持1024・3072・8192・12288）だけで学習し、凍結する（`fit_readouts`、`scaling_final`と同じ）。

**物理的な制約：**
- 蹴りを受けるのは、読み出し素子だけである。P・R・Mには何も戻らない。
- そのため、回路本体の連鎖は読み出しによって変わらない（テストで確認した）。
- 選択には、診断用の正確な記憶を一切使わない（テスト）。

**E7-Aとの違い：**E7-AのT7ゲートの発火競合を、閾値の素子に置き換えた。符号（判断までに発火したか）が出そろうのが判断の時点なので、競合させる時間がないためである。

**記述として報告するもの（提言1・2・5・6）：**

## 6. 言えること・言えないこと

**closed_loop_promisingの場合に言えること（探索、この5回路）：**
- 記憶の写しの読み出しで準備を選ぶ回路は、リセットなしの連続計算で、それまでの回路の判断器より良い。
- 同じ二候補の外部選択との差は5pt以内である。

**言えないこと：**
- 確証。
- 新しい回路への一般化。
- 24候補の外部選択に近いこと（二候補の制約があり、実現可能性で約22pt劣る）。
- 自己学習（読み出しの重みは外部で学習した）。
- 必要な振動子の数の法則（提言3・4の解析は、この評価の後に、別の探索として行う）。
