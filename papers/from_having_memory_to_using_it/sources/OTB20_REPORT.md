# OTB20：固定核の誤差増幅を制限する試験

2026-11-05。[全gridと検証を含む詳細報告](main_20261105/REPORT.md)を参照。

**保護の十分条件は満たせたが、その入力制限では対象の反転学習も止まった。**

反転世界・各条件32caseで、通常誤差の待ち0/2,048は対象更新32/32・非対象帯保持16/32。
待ち4,096の通常誤差は、対象更新と非対象保護を32/32で両立した。
bounded誤差は待ち0/2,048/4,096のすべてで非対象32/32保護、対象更新0/32だった。

固定T7・相方・e/s則は変更せず、外部教師誤差の振幅だけを制御した。
今回の結果は、保護の上限と、指定時間内の対象書込みに必要な下限を同時に扱う必要性を示す。
短い固定待ちの結果も探索であり、一般的な安全・効率の保証ではない。

全576試行の書込み全stepを計測し、[独立計算の監査](main_20261105/audit.json)を通過。
4本32,000 stepの全状態を別記述の式で再計算した。
[別担当の追加監査](main_20261105/audit_independent.json)では全条件のgain・採点、OTB19と重なる128件の各境界一致も確認した。
