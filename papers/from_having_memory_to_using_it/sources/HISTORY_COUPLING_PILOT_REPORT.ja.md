# 履歴と運動の結合：探索pilot実験報告

実行日：2026-11-06。**探索結果であり、事前登録された確証実験ではない。**

今回の5回路では、準備選択器を同じ予算で再学習しても、処理振動子Pの境界以前の記憶成分が位相に与える寄与を除くと、7回連続成功率が低下した。一方、固定準備では履歴介入が改善をもたらし、履歴移植後の情報更新による選択の改善も確認できなかった。「記憶は常に有益」「知能の種を同定した」という結論にはならない。

## 実行範囲

- 出発点：oscillator-arithmetic の `01d84b5a41cc8d521724bbaa0127601b086b9936`。既存の確証結果と実装は変更していない。
- 既存の固定5回路（200–204）、保持時間512・16384、従来と同じ準備候補2つ・時間スケジュール。
- 各回路で訓練8履歴群、評価16履歴群。1群4行。両保持時間は同じ群・入力列を再利用する。
- 1条件・1方策あたり640評価チェーン。最初の計算後に介入し、その後7回を採点。5条件×4方策、計12,800評価チェーン。
- 同じチェーンを条件間で対応づける。12,800独立標本、640独立回路という意味ではない。
- 訓練・評価は別のpilot用乱数系列。既存確証の入力は通常条件の回帰検査だけに使用。
- 取得処理の実測時間100.39秒。環境構築・事前検査・事後解析は含まず、ハードウェア効率の主張には使わない。

## 条件と比較

|条件|処理振動子Pへの操作|解釈上の注意|
|---|---|---|
|B0|通常のT7|比較基準|
|B1|最初の境界以降、Pのκを0にする|現在入力がm経由で作用する経路も切れる。過去だけの対照ではない|
|B2_once|最初の境界で、mと訓練由来参照値との差の減衰成分を以後の位相計算から除く|m自体は消さない。介入効果は減衰しながら持続|
|B2_repeat|各準備境界で同じ除去成分を設定し直す|反復するモデル内部介入|
|B3|境界以降、発火時にmを0へ|発火時mリセット型T7。LIFではない|

B2は補助変数hを用い、介入境界で `h = m − m_ref`、以後 `h_next = (1−ε)h`、位相計算には `m−h` を使う。参照値は元の訓練で得た128閾値の中央値。境界後の入力はmへ入り続ける。位相、不応期、他ユニットの履歴は残るため、すべての履歴を消す操作ではない。発火の変化は後続mにも影響する。

方策は凍結E7-D読み出し、同一予算で再学習した線形読み出し、訓練から選んだ固定候補、診断用oracleの4つ。再学習は各条件448意思決定行／回路、ランダム方策の訓練軌道から行った。ハイパーパラメータや評価データを使った調整は行っていない。凍結読み出しの元の訓練量は異なるため、公平な予算比較は再学習同士で行う。

読み出し側のκは0にしない。B3では既知入力と観測発火から再構成した記憶に基づきコピー補正を行うため、コピー維持則も変更される。これは読み出し装置を完全に不変にした対照ではない。実際のPのmをオンライン選択器に渡してはいない。

## 全7回成功率

すべて分母640。以下は実際に与えた次入力に対する成功率。

|条件|凍結読み出し|再学習|固定準備|診断oracle|
|---|---:|---:|---:|---:|
|B0 通常|58.28%|59.69% (382/640)|36.09%|59.38%|
|B1 Pのκ=0|0.31%|0.31% (2/640)|0.31%|0.31%|
|B2 単発|48.75%|52.66% (337/640)|48.91%|56.88%|
|B2 反復|40.31%|46.56% (298/640)|45.94%|52.50%|
|B3 発火時mリセット|41.72%|48.59% (311/640)|45.94%|50.00%|

診断oracleは各時点で4つの標準プローブに同時成功できる候補を選ぶ。真の状態を用いる特権的診断で、全7回成功を大域最適化していない。別方策とは将来の軌道も異なり、他方策の全7回成功率の上限ではない。

再学習同士のB0との差は次の通り。

|比較|全7回成功率の差|記述的95%区間|直後1回の差|
|---|---:|---:|---:|
|B2単発 − B0|−7.03ポイント|[−10.16, −4.06]|−5.47ポイント|
|B2反復 − B0|−13.13ポイント|[−16.25, −10.00]|−3.13ポイント|
|B3 − B0|−11.09ポイント|[−13.75, −8.44]|−7.66ポイント|

区間は固定5回路内で履歴群を対応づけて再抽出する4,000回のbootstrap。保持時間も対応を保つ。回路母集団への一般化、訓練の乱数変動、多重比較補正を含まない。確証の有意判定には使わない。

B2の全7回の差は、再学習後も5回路すべてで負だった。単発では回路ごとに−15.63〜−2.34ポイント、反復では−31.25〜−3.13ポイントとばらつく。直後1回と連鎖全体は別の指標であり、反復の効果を単発効果の単純な累積とは解釈しない。再学習方策自体も条件ごとに異なる。

## 不利な結果と失敗の内訳

**履歴を残すだけでは良い成績にならない。** 固定準備では通常36.09%に対しB2単発48.91%、反復45.94%だった。この3条件では5回路とも同じ固定候補1が選ばれており、固定候補変更による差ではない。通常条件では再学習による改善が固定準備比+23.59ポイントあるが、B2単発では+3.75、反復では+0.63ポイントに縮む。これは履歴の有用性が利用方策に依存することと整合する。ただし管理機構との一般的な相乗効果の確証ではない。

候補の成否には2種類の評価がある。標準4プローブをすべて通る「共同準備可能性」は選択器の訓練目標。保存した実際の次入力で成功できるかは失敗解析専用で、選択器には渡していない。

|再学習条件|実入力での失敗数 / 4,480計算|どちらの候補でも失敗|成功候補はあるが別を選択|
|---|---:|---:|---:|
|B0|463|142|321|
|B2単発|614|166|448|
|B2反復|703|466|237|
|B3|754|120|634|

最後の列は実入力に対する事後診断であり、その未来入力を知らない選択器の誤学習率とは一致しない。たとえばB3では共同準備可能な場面に限った選択失敗率は1.64%だが、実際の連続成功は低い。候補不足・訓練目標・実タスクを区別する必要がある。

再学習B0でもA=0の全7回成功94.69%に対しA=1は24.69%。B2単発では95.63%と9.69%。平均値だけで全入力条件に頑健とは言えない。

B1は全5回路、B2反復は回路202で訓練ラベルが単一クラス／空となり、仕様どおり訓練から選んだ固定候補へフォールバックした。B1の大幅低下を「過去が知能に必須」とする根拠には使わない。

## 履歴移植：今回、読み出し更新による救済は確認できなかった

最初の準備境界のみ、A・現在B・不応期が一致し、別履歴群かつ位相差0.5rad以内の最近傍をドナーとした。Pのmだけを移植し、受け手の他状態・将来入力を固定した。640行中624行が適格。平均絶対m変位は0.01470で、小さい介入だった。

ここでの読み出しは正確なmから作る既存の閾値特徴を使った**オフライン診断**。実際のコピー振動子による読み出しではない。下表は全7回成功率でも実次入力成功率でもなく、標準4プローブに同時成功する候補を選んだ割合。

|診断条件|共同準備成功 / 適格624行|
|---|---:|
|元の状態・元の読み出し|75.96%|
|状態は元のまま、読み出しだけ移植後のmへ|75.48%|
|m移植・読み出しは古いまま|76.44%|
|m移植・読み出しも更新|76.28%|
|m移植・元の状態でのoracle選択|79.17%|
|m移植・移植後のoracle選択|80.77%|

既存の正確m読み出しを更新しても改善せず、救済仮説はこのpilotでは支持されない。oracleでは+1.60ポイントの余地があるが、自律的な能力の証拠ではない。選択された小変位の部分集合であり、強い同等性・一般的な無効果も結論できない。この結果を見てドナー条件を変えた再取得は行っていない。

## C1・C2・C3への位置づけ

- **C1：履歴成分が因果的に効くか。** B2介入で凍結選択器の成績が変化し、モデル内の因果寄与を支持する。参照値を含む特定の介入についての結果であり、実機で可能な操作や知能の同定ではない。
- **C2：役に立っているか。** 今回の固定5回路・候補・再学習予算では、通常系の方がB2より全7回成功率が高い。探索的な支持。ただし固定準備では逆転するため、履歴の有用性を管理方法から切り離して主張しない。
- **C3：管理と噛み合っているか。** 方策による逆転は追究に値するが、直接の移植・情報更新による救済は未確認。今回の実験でC3成立とは書かない。

## 監査と再現性

1. 元のNumPy実装との状態・発火・特徴・候補ラベル・選択一致を確認。
2. 既存確証の回路200・保持512について全192群で成績と準備可能性を再現。既存確証全体を再実行したわけではない。
3. 取得前のコード・設計SHA256を保存し、事後の一致を確認。200評価ファイルに有限値、共通介入前状態、保存候補予測と実現結果の一致を確認。
4. 観測からのshadow再構成誤差は0。コピー振動子の誤差は別で、元の1step遅延等による最大約0.6の差を記録している。コピーそのものが常時完全一致するという意味ではない。
5. 結果を見ずに選んだ回路200・204、両保持時間、全条件、凍結／再学習の計240軌道を別のスカラー更新コードで再計算。発火数・成否・終状態が一致し、最大絶対誤差0。

これは同一作業内の別実装検査で、外部研究者の独立追試ではない。取得前のNumba型エラー・検査用入力形状エラーと、事後監査のimport衝突もログに保存した。修正後、取得は1回のみ。取得後に条件・方策を調整していない。

元の保存モデルはscikit-learn 1.9.1、今回の環境は1.8.0。凍結推論は保存されたスケーラ・線形係数を明示計算し、既存出力と照合した。元の環境そのものを再現したという主張ではない。

## 論文に使える範囲と次の確証実験

現時点で書ける主張：

> In an exploratory pilot on five fixed oscillator circuits, removing the pre-boundary memory contribution from phase evolution reduced seven-step success even after equal-budget readout recalibration. The direction reversed under fixed preparation, indicating that the benefit of retained history depended on how preparation was selected. Updating an exact-memory readout after matched memory transplantation did not yield a rescue in this pilot.

固定5回路、2候補、小さい訓練集合、外部での読み出し学習、シミュレーションという範囲を必ず併記する。B2は位相速度の動作点も変えるため、履歴内容の有用性と動作点の効果を完全に分離したわけではない。再学習は限定された特徴クラスとランダム軌道訓練で、変更後基板の最善能力ではない。今回、OTB型の新関係学習・旧関係保持は測っていない。LIF／ALIF、MC中継課題との比較も追加していない。

次の確証では、主比較をB0対B2単発・再学習に置くかを設計として先に決め、効果量と撤回条件、群数、候補、参照値、動作点対照、評価手順を固定する。反復条件と固定準備の逆転は重要な副比較として残す。移植実験は変位量・読み出しが区別できる範囲を訓練側で設計し直す必要がある。今回の評価データを再び未使用cohortとは扱わない。

今回の成績だけで「知能の種が証明された」とは書かない。一方で、**保持した履歴をどう利用可能にするか**という論文の問いに、支持と反例の両方を提供する探索結果になった。
