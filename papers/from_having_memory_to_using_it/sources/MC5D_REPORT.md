# MC-5D（探索・事前登録なし）：T7中継の不利は、発火率の違いか、負の位相速度の巻き戻りか

## 結論

**どちらでもなかった。T7中継の不利は、発火率をそろえても、位相の巻き戻りを止めても残る。**

1. **発火率をそろえても残る。**S・Fの発火率をT7とLIF（不応期32）で同程度にそろえた3つの水準すべてで、LIFのRの判断がT7を上回った（`both` 0.589対0.486、0.683対0.500、0.566対0.517）。
2. **負の位相速度の巻き戻りは原因ではない。**元のT7で位相が負になるのは、全ステップの0.1〜0.7%程度（低い発火率のFで最大6.7%）と少ない。位相を0で止めた別素子（t7clip）にしても、Rの判断は0.502 → 0.509（制約なし）、水準ごとでも+0.002〜+0.020しか変わらない。
3. **T7中継は、同じ発火率でも、発火が運ぶ信号が少ない。**中継の発火と目標の相関は、同じ発火率の水準で、遅い役割（S）でT7 0.48〜0.62対LIF 0.67〜0.80、速い役割（F）でT7 0.23〜0.34対LIF 0.35〜0.66。

MC-5Cの主判定や結論は、この探索によって変更しない。この探索は、MC-5Cの副次比較で残った論点（Issue #129 の指摘1、Issue #125 の指示5）を切り分けるためのものである。

## 何をしたか

- 回路は探索用の200〜204。MC-5Cの確証に使った380〜399は使っていない。乱数種は新しい基数（7,100,000 + 100×回路 + 分割番号）。課題・記憶集団（fast）・中継の時定数（S 1000、F 100）・R・重みの決め方はMC-5Cと同じ。
- MC-5Cの凍結したコードは変更していない。新しい素子と選択の仕組みは[mc5d.py](mc5d.py)に書いた（MC-5Cの照合スクリプトは引き続きPASS）。
- **中継の種類：**
  - t7（元のモデル、不応期32）
  - t7clip（位相が負になったら0で止める。元のモデルとは別の素子として、診断にだけ使う）
  - lif32（LIF、不応期32）
  - lif8（LIF、不応期8、MC-5Cの主条件と同じ素子）
- **発火率をそろえる方法（[PLAN_RATE_MATCHED.md](../mc5c_relay_confirm/PLAN_RATE_MATCHED.md)）：**利得と動作点の格子（7×6、MC-5Cと同じ）のうち、検証データでの発火率が目標の±20%に入るものだけを候補とし、その中で相関が最大のものを選んだ。目標は3つの水準で、S {8, 15, 25}、F {4, 8, 15}（1000ステップあたり）。比較のため、制約なしの選択（MC-5Cと同じ）も載せた。
- 5回路の平均と回路ごとの値。探索なので合否は判定しない。

## 分かったこと

1. **同じ発火予算で比べても、T7中継はLIF中継に大きく劣る。**3水準すべてで、lif32のRの判断はt7を上回り（差 +0.10〜+0.18）、回路ごとにも同じ向きだった。MC-5Cの副次比較の差（−0.189）は、発火率の違いだけでは説明できない。
2. **情報は、同じ発火率でも中継の段階で失われている。**特に速い役割（F）の相関がT7で低い（0.23〜0.34）。MC-1b・MC-2で見た「T7は直近の変化への追従が遅い」と一致する。T7は入力が速さを少しずつ変える積分型の素子で、LIFのような閾値の鋭い応答を持たない。
3. **負の位相速度の巻き戻りは、T7の不利の主な原因ではない。**巻き戻りの起きるステップは少なく、位相を0で止めても判断はほとんど変わらない。
4. **発火率を1つの値に縛ると、LIFも制約なしより下がる**（lif8：制約なし0.709、水準1で0.612）。今回の水準の置き方では、どの素子にも最適とは限らない動作点を強いている。それでも、同じ制約のもとでT7が一貫して下回った。

## 結論の範囲

- 探索（5回路）。発火率の水準は3つ、±20%の許容は事前に決めたが、確証ではない。
- 「同じ発火予算でもT7中継が不利」は、この課題・この時定数（1000・100）・この格子の範囲での結果である。
- 原因は「T7の発火が、同じ発火率で運ぶ信号が少ない」ところまで絞れた。その内訳（積分型の応答、恒常性による発火率の制御、発火時刻のばらつき）は、まだ分離していない。
