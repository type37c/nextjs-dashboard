## 2. 凍結して変えないもの

**E7-Dの判断器：**`results/e7d_closed/cal_{200..204}.pkl` を、SHA-256を照合して読み込む。次のものを含み、すべて探索のときと同じである。
- 読み出しの閾値（Pの記憶の分位点、128個）。
- 線形の重み（K = 16、64）。
- 切り替えの規則（Aの符号、蹴りの後のPの発火の4区分）。
- 蹴りの時刻（計算の窓の128ステップ目）と大きさ（+G、−(1−ε)G）。
- 判断の窓（D）と閾値の素子（z > 0 なら v）。

**比較の方式も、すべて凍結したものを使う：**
- E7_FROZEN：E7-Aの較正。
- E7_MIX：E7-C0bの `fits_*.pkl`。
- ANA2：同じ二候補の外部の影。
- SYNC_WARM24：E5の外部の24候補選択。
- FIX2、A_ONLY。

**計算の経路：**確証の `run_job` は、探索の `run_e7dc.run_job` と同じ計算の経路である。探索のcohortと入力を与えると、探索の記録をビット単位で再現する（`test_e7dcf.py`）。

**同じ条件の比較：**8つの方式を、同じ初期状態・同じ課題の列（同じcohort、同じ入力 B）で比べる。

## 4. 主判定（探索と同じ。変更しない）

|条件|内容（7回全正答、計算1〜7）|基準|
|---|---|---|
|F1|E7D_64 − E7_FROZEN|平均 ≥ +5pt、かつ95%下限 > 0|
|F2|E7D_64 − E7_MIX|95%下限 > 0|
|F3|E7D_64 − ANA2|95%下限 > −5pt（非劣性。基準を変えない）|

**推定と区間：**
- 回路ごとに、群（4行）を再標本する（回路は固定）。
- 比の推定量で回路ごとの値を求め、5回路の平均をとる。
- 区間は、百分位点の95%区間である。全対比で、同じ再標本の添字を使う（対応のある比較）。

**多重性：**主張は、F1・F2・F3がすべて成立したときだけ行う（交差・和の原理）。このため、多重性の調整は要らない。

**副次の判定（主判定が成立したときだけ、この順に検定する固定順序法）：**

|判定|内容|
|---|---|
|S1|5回路それぞれで、E7D_64 − E7_FROZEN の回路別の95%下限 > 0|
|S2|5回路それぞれで、E7D_64 − E7_MIX の回路別の95%下限 > 0|

**妥当性：**次のどれかが成り立たなければ、主張はしない。
- 凍結の照合（計画・ソース・入力・独立性の監査）。
- 実行時の独立性の監査に合格すること。
- 実行が一度だけであること（ロックファイル、記録が20件）。

## 6. 記述として報告するもの（判定には使わない）

- **回路単位：**5回路を標本とみなした平均と t の95%区間（4自由度）、正になった回路の数。F1〜F3のそれぞれ。新しい回路への一般化の目安としてだけ示す。
- **失敗の分解（計算1〜7）：**
  - その状態で二候補のどちらも成功できない。
  - 成功できる候補があったのに、選択を誤った。
  - そのうち、正確な記憶で読めば正しく選べた分（読み出しの誤差）。

- **段ごと：**正答率、成功候補の存在率、選択の成功率（連鎖の中での状態変化）。
- **判断の質：**片方だけが成功できる判断、片方以上が成功できる判断での選択の成功率、選択の失敗率。
- **読み出しの誤差による選択の変化：**変化、悪化、改善。
- **写しの記憶の誤差：**段ごと（蓄積）。
- **E7D_16とE7D_64の差。**
- **SYNC_WARM24との差：**二候補の制約。

## 7. 言えること・言えないこと

**主判定が成立した場合に言えること：**
- この5回路で、新しい入力群に対して、次のことが確証される。
- Pの記憶の写しを振動子で持ち、可逆な蹴りと線形の重みで読み出して準備を選ぶ回路は、リセットなしの連続計算で、それまでの回路の判断器（凍結したE7、学び直したE7）を上回る。
- 同じ二候補を外部の影で選ぶ方式との差は、5pt以内である。

**言えないこと：**
- 新しい回路への一般化。
- 24候補の外部選択に近いこと。
- 自己学習。
- T7固有の利点（対照の比較は、確証の後に別の探索として行う）。
