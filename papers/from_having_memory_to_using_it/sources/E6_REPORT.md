# E6（確証）：Pの記憶の因果的な役割と、準備の経路の同等性

## 結論

**事前登録した4つの仮説は、固定順序ですべて達成し、すべて主張できる。**前提条件もすべて成立した。
- 影は全段で一致した。
- ORCは、元の系79.1%、対照系80.6%で、40〜95%の範囲にある。
- 陽性対照（Aの反転で最良の候補が変わる行）は74.4%だった。

|順|仮説|推定値|区間|基準|結果|
|---|---|---:|---|---|---|
|1|**H_A** 記憶への±0.5単位の介入で、介入前に選んだ（成功していた）準備が失敗に変わる割合|**20.3%**|95%：19.9〜20.8|下限 > 5%|**達成**|
|2|**H_B1** 介入を知らせた選択 − 知らせない選択（±0.5単位）|**+17.9pt**|95%：+17.4〜+18.4|下限 > 0|**達成**|
|3|**H_B2a** FULLの7回全正答率：記憶経由の準備 − 位相経由の準備|**−0.43pt**|90%：−1.18〜+0.34|TOST ±3pt|**達成（同等）**|
|4|**H_B2gap** ORC連鎖とFULL連鎖の性能差の、系の間の比較：(ORC − FULL)_記憶経由 − (ORC − FULL)_位相経由|**−1.16pt**|90%：−1.80〜−0.52|TOST ±3pt|**達成（同等）**|

**H_B2aの主張の限定（事前に固定した規則による）：**回路別のB2aは −6.0、−16.1、+12.5、+0.9、+6.5pt だった。|差| > 5pt の回路があるため、主張は「**この5回路の平均として同等。どちらの経路が有利かは回路によって異なる**」に限定する。

回路差の大部分は、存在上限の差（−7.8、−17.6、+12.8、−0.7、+5.3pt）による。ORC連鎖とFULL連鎖の性能差の系間比較（H_B2gap）は、回路別でも −1.8〜+0.4pt に収まった。

**Issue #130を受けた解釈の限定（事前登録した数値と判定は変更しない）：**
- **H_A**が示すのは、「**介入前に選ばれた準備の成功可能性が、記憶に因果的に依存する**」ことである。成功できる準備が存在するかどうか（到達可能集合 R_U = any_u ready）そのものの変化ではない。存在については、下の事後の診断を参照。
- **H_B2gap**は、ORCとFULLがそれぞれ別の状態の軌跡を走る**7回連鎖の性能差を、系の間で比べたもの**である。同じ状態集合での純粋な選択の損失ではない。ORC連鎖が、FULL連鎖の訪れた状態の上限を与えるとも限らない。状態を揃えた選択の損失は、下の事後の診断で別に測った。

### 到達可能集合への介入の効果（元の系、単発の計算、5回路平均、95%区間）

|介入|成功候補が存在する行（前 → 後）|存在を失った行|存在を得た行|成功候補の数（前 → 後）|入れ替わった候補の数（24中）|選択が失敗に変わった行（全行に対して）|うち、別の候補はまだ成功できる行|
|---|---|---:|---:|---|---:|---:|---:|
|−0.5|94.9% → 96.6%|2.0%|3.7%|5.26 → 5.46|1.71|18.3%|16.3%|
|+0.5|94.9% → 95.7%|2.9%|3.7%|5.26 → 5.06|1.79|19.8%|17.0%|
|−1|94.9% → 96.3%|3.7%|5.1%|5.26 → 5.46|3.03|38.0%|34.3%|
|+1|94.9% → 94.0%|6.0%|5.1%|5.26 → 4.96|3.23|44.1%|38.1%|

**読み方：**
- 記憶への介入は、**成功できる準備が存在するかどうかを、ほとんど変えない**（存在の正味の変化は、−0.9〜+1.7pt）。
- 変わるのは、**どの準備が成功するか**である。24候補のうち、平均1.7〜3.2候補の成否が入れ替わる。
- 選んだ準備が失敗に変わった行の約87〜89%では、別の準備がまだ成功できる。
- したがって、記憶が変えるのは「到達可能集合の大きさ」ではなく「到達可能集合の中身（どの準備がそこに入るか）」である。そのため、記憶を知らない選択は失敗する。

### 状態を揃えた選択の損失（FULLが実際に訪れた状態、各段）

regret ＝ 1[何らかの候補が成功する] − 1[FULLの選択が成功する]。FULLの連鎖を、評価と同じ軌跡で再実行して求めた（正誤が評価のbankと一致することを検査した）。

|位相経由|92.8%|91.8%|1.00%（0.92〜1.08）|
|差（記憶経由 − 位相経由）| | |−0.14pt（−0.24〜−0.04）|

- **読み方：**全状態を使う選択器は、成功できる準備が存在する状態では、どちらの系でもほぼ必ず（99%前後）それを選んでいる。
- **残る損失の出所：**7回全正答の損失の大部分は、選択ではなく、成功できる準備が存在しない状態（各段7%前後）から来る。

## 判定コードの修正（Issue #130の指摘3）

- **元の実装の問題：**`decide()`は、主張できるかどうか（`claimable`）を統計量だけで決めていた。前提条件の判定（`decision_valid`）は、`main()`で後から付け加えていた。前提条件が成立しなかった場合でも、`claimable=true`が残り得た。
- **修正：**`decide()`の中で前提条件を判定し、成立しない場合は、すべての仮説を主張不可にして`decision_status='no_decision'`を返すようにした。回帰テストを2件追加した。
- **今回の結果への影響：**前提条件は成立していたので、保存した判定（4仮説すべて主張可能）は修正後も同一である（再計算で確認）。
- **実行後の修正の記録：**`run_e6c.py`のSHA256は、凍結時の`b284576a…`から`fc432200…`に変わった。`protocol.json`と`source_hashes.json`は、凍結時の記録として変更していない。

## 何が言えて、何が言えないか

**言えること（この5つの既知の回路、新しい入力群に対して）：**
- Pの記憶への局所的な反実仮想介入は、その前に選んだ準備を用量に応じて失敗させる。±0.5単位（記憶のSDの約0.23倍）で約20%。**選ばれた準備の成功可能性は、記憶に因果的に依存する。**
  - 事後の診断では、成功できる準備が存在するかどうかはほとんど変わらず、どの準備が成功するかが変わった。
- その変化を知る制御器は、成功を保てる（+17.9pt）。
- 準備のパルスを記憶ではなく位相に加えても、次の2つは±3ptの範囲で同等である。
  - 全状態を使う選択の成績（5回路の平均として。回路ごとには、どちらが有利かが異なる）。
  - ORC連鎖とFULL連鎖の性能差（回路ごとにも小さい差）。これは異なる軌跡の比較であり、状態を揃えた選択の損失ではない。状態を揃えた損失は、事後の診断で両系とも約1%だった。
- したがって、**readiness制御の利益は、記憶状態を追跡して利用することから生まれる。準備の経路として、記憶が運動を変えることに固有の利益は見られない。**

**言えないこと：**
- **計算窓での記憶と運動の結合は、両系に残っている。**そのため、「記憶と運動の結合一般が計算に不要」とは言えない。
- **自然な物理過程として記憶が書き換わる場合の効果。**記憶の直接の書き換えは、反実仮想による因果の診断である。
- **新しい回路への一般化。**利用できる回路は5つだけである。
- **回路が自律的に準備を判断すること。**推定と選択は外部で計算した。
- **第一論文の主張との関係：**第一論文の主張（記憶依存回路でのreadiness制御）とは別の、追加の因果的主張である。
