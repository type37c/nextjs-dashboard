# E3b：学習を強化したGRUで、初期化なしの連続計算を解けるか

## 結論

**学習に成功すれば、小さなGRU（隠れ15）は初期化なしの8回の連続計算をほぼ完全に解く。ただし、学習に成功するのは20モデル中5モデルだけだった。**

- **学習できたモデル**（検証の7回全正答が0.9以上）：条件ごとに5通り中1〜2（計5/20）。残りの15モデルは、E3と同じく自明な解にとどまった。
- **窓信号なしの条件**で学習できたモデル（768系列・6144系列で各1モデル）：未較正4保持と保持16384の両方で、A=0もA=1も7回全正答が**100%**。訓練では保持0しか見ていない。
- **窓信号あり・6144系列**で学習できた2モデル：全行97.4%（A=0 94.8%、A=1 100%）。保持16384ではA=0が82.0%に下がる。
- **窓信号あり・768系列**で学習できた1モデル：A=1が76.4%で、保持16384では28.0%。部分的な解にとどまる。
- 事前に決めた区分「GRUが課題を解く」（学習できたモデルでA=0・A=1とも95%以上）に当てはまるのは、窓信号なしの2条件。

**T7との位置づけ（並べて示すだけ）：**同じ入力の流れで、T7＋観測選択（E2）はA=0 99.0%・A=1 10.5%。T7で外部から状態を戻さずに届く上限（24候補の貪欲oracle）はA=1 59.8%。**学習に成功したGRUは、外部からの初期化なしで、T7のどの準備方式よりも長く計算を続けられる。**T7がGRUより優れるという主張は、この比較からはできない。

## 何をしたか

[事前設計](DESIGN.md)を`PROTOCOL.md`と`results/e3b_gru_training/protocol.json`へ固定し、コミット`4d1aadb`でpushしてから実行した。

- **設計前の予備実験（開示）**：E3の訓練cohortと予備の検証cohortだけで、学習手順を4通り試した（`pilot.py`、`pilot.json`）。勾配の切り詰め1.0と正例の重み3を使い、保持0で長く学習する手順だけが、自明な解を抜け出した。
- **固定した手順**：保持0だけで学習、Adam 3e-3、ミニバッチ64、2000更新。100更新ごとに保持1024の検証で最良の重みを選ぶ。4条件×乱数5通り。
- **実行の中断と再開（開示）**：最初の実行は、バックグラウンドの60分の制限で、20モデル中18モデルを終えた時点で停止した。
  - 終えた18モデルの重みと評価結果は保存されていた。学習の記録（最良の更新番号と経過）はメモリ上にしかなく、失われた。
  - `resume_e3b.py`で、残り2モデルを同じ凍結済みの`job`関数で学習した。終えた18モデルは学習し直さず、保存した最良の重みから検証の成績を計算し直した。そのうえで、凍結済みの`main`の集計をそのまま実行した。
  - 計算し直した18モデルの検証成績は、最初の実行の標準出力の記録（`first_run_stdout.log`）と全件一致した。
  - 18モデルについては、`results.json`の`best_update`と学習の経過が空になっている。

## 解釈

1. **E3の失敗は、学習手順によるものだった。**手順を強化すれば、隠れ15のGRUでも課題を解ける。窓の時刻を知らせる信号がなくても解け、訓練の4倍以上長い保持でも崩れない。
2. **ただし、学習は不安定である。**同じ手順でも、乱数によって成功するのは4分の1にとどまる。
3. **T7との違い。**GRUは、全重みを各窓の正解で学習し、記憶を保ちつつ新しい入力に乱されないゲートを自分で作る。T7は物理が固定で、学習するのは準備の選択だけである。E2〜E2cで見た「計算後の状態が次の計算を妨げる」問題は、学習で内部の更新規則そのものを変えられるGRUには起きない。
4. **論文での位置づけ。**本研究の主張は、従来方式に対する優位ではなく、「物理が固定された記憶依存振動子では、準備可能性が測定・制御すべき性質になる」ことに置く。GRUは、更新規則まで学習できる場合の参照点として示す。「なぜGRUでなく振動子か」には、優劣ではなく「更新規則を学習で変えられない基板（物理デバイスなど）で、どう計算を続けるか」という問題設定で答える。

## 検証

- **予備実験とスモークテスト**：配管の確認は、出力先を作業用ディレクトリにし、指標を表示せずに行った。
- `verify_e3b.py`：独立監査に合格。確認した内容は以下のとおり。
  - 全保存物のSHA256。
  - 学習できた／できないの判定と、検証成績の整合。
  - 各条件のseed 0と4の重みを読み込み直し、回路200・204の保持16384の判定を再計算して、保存した正誤と全行一致すること。
  - 全条件・両集計の全指標の再計算。
- 計算し直した18モデルの検証成績は、最初の実行の記録と全件一致した。

## 主張しないこと

- この手順と予算（2000更新、乱数5通り）での結果であり、GRUの成功率の一般的な値ではない。
- T7とGRUは時間分解能（GRUは1/4）と学習できる対象が違うので、勝敗は判定しない。
- 物理デバイスとしての優劣は主張しない。
