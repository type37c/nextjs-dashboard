# MC-4X（探索・事前登録なし）：多時定数の記憶は、出力振動子Rの判断に伝わるか

## 結論

**伝わらなかった。**どの記憶集団でも、出力振動子Rの判断は偶然の水準（主指標0.5）をほとんど越えなかった（最良の混合集団で0.531）。

ただし、原因は切り分けられた。

- **Rへの実装による損失は小さい。**Rが実際に受け取るのと同じ量（集団の発火をRと同じ漏れ0.99で積分した値）から外部の線形分類器で判断しても（EXT-R）、0.55を越えない。Rは、その外部の参照とほぼ同じところまで来ている。
- **足りないのは、Rの積分時間の中にある情報そのものである。**同じ集団の発火を時定数1600で積分すれば、外部の分類器は0.60〜0.73まで判断できる（EXT-1600）。遠い窓の情報は、R（時定数約100）の積分時間の外にある。
- **長い積分を許すと、多様性の利点は消え、結合のない対照（PK）とも差がない。**EXT-1600では、速い集団（0.725）、混合（0.698）、PK（0.702）がほぼ同じ。

つまり、MC-2・MC-3で見た「遅い情報を読むには、読む側に長い積分が要る」が、ここでは**受け取る側の振動子Rの時定数**として、計算の成否を決めている。

## 何をしたか

[PLAN.md](PLAN.md)（v2、レビュー対応済み）のとおり。**事前登録なし**の探索で、回路200〜204、評価ストリーム32本（各24,000ステップ）。

- 課題：Bの時刻tで、Rが[t+1, t+60]に発火すべきなのは、遠い窓[t−1500, t−250)にAがあり、直近の窓[t−250, t)にAがないときだけ。Aの頻度1/1375、Bの最小間隔130。
- **主指標`both`：**「直近の対比」（遠いあり・直近なし 対 遠いあり・直近あり）と「遠い対比」（遠いあり・直近なし 対 遠いなし・直近なし）の正答率の小さい方。常に発火する・しない判断、遠い窓だけ・直近の窓だけを見る判断は、どれも0.5になる。
  - **実装時の訂正：**当初は4種類の正答率の平均を主指標にする予定だったが、一度も発火しない判断が0.75になることが分かったので、`both`に変えた（PLAN.mdに経緯を記載）。
- Rの重みは、訓練データで集団の発火をRの漏れ0.99で積分した値からリッジ回帰で決め、全体の倍率cとBの利得bを検証データで、Rの実際の発火による「`both` − 誤警報率」で選んだ。
- 区間は、回路ごとに評価ストリームを再標本化した95%区間（1000回）。

## 分かったこと

1. **Rはほとんど発火しない判断に落ち着いた。**どの集団でも、発火すべき履歴（遠いあり・直近なし）での正答率は0.02〜0.25だった。誤警報を避ける選び方のもとで、Rは「黙る」方に寄る。主指標が0.5付近なのはこのためである。

2. **Rの損失は「発火素子への実装」ではなく「積分時間」である。**
   - EXT-R（Rと同じ漏れの積分値から、外部で判断）でも、混合集団で0.546、それ以外は0.5未満。Rの時定数（約100）で集団の発火を積分した値には、遠い窓の情報がほとんどない。
   - EXT-1600（同じ集団の発火を時定数1600で積分）では、遠い対比が0.87〜0.89まで上がる。**情報は集団の発火にあるが、Rの時定数では読めない。**MC-2（瞬時の発火から読める遠い記憶は小さい）、MC-3（遠い記憶を読むには同程度の積分が要る）と同じ現象が、外部の読出し器ではなく、受け取る側の振動子で起きている。

3. **混合集団の小さな利点は、両方の半分を必要とする。**R：splitの0.531は、遅い半分の出力を無効にすると0.500（Rが完全に黙る）、速い半分の出力を無効にすると0.451（Rの発火が乱れ、誤警報が増える）に落ちる。片方だけで重みを選び直しても0.49。ただし、効果そのものが小さい。

4. **長い積分を許すと、多様性の利点も、記憶と運動の結合の利点も消える。**EXT-1600では、速い集団（0.725）が混合（0.698）とPK（0.702）と同等以上だった。読出し側が長く積分すれば、遠い記憶は読出し側が持つことになり、集団に遅い素子を置く必要がなくなる。

5. **相互結合Jは効かない**（R：split 0.531 対 J=0 0.532）。MC-2と同じ。

## 研究の問いに対して

> 多時定数の記憶を、振動子間の計算に使えるか。

この回路（記憶集団 → 時定数約100の出力振動子1個）では、**使えなかった**。原因は、受け取る側の振動子Rの積分時間が、記憶の時間スケールより短いことにある。外部で復号できる情報（EXT-1600）は、Rの時間スケールに入ってこない。

これは「どんな記憶を持つ振動子を、どこに置けば、次の計算が可能になるか」という設計問題の、最初の具体的な答えでもある。**遅い記憶を使う計算には、受け取る側にも同じくらい遅い時間スケールが要る。**記憶集団に遅い素子を置くだけでは足りない。

## 次の候補（MC-5）

1. **受け取る側にも遅い振動子を置く。**Rの前に、遅いT7の中継素子（記憶が速さを変えるので、κで積分時間を選べる）を置き、遠い窓の情報をRの時間スケールまで運ぶ。ここで「記憶と運動の結合」が、受け取る側の時間スケールを設計するつまみとして意味を持つかを調べる。対照は、同じ時定数の単なる漏れ積分器（結合なし）。
2. **Rの時定数そのものを変える。**Rの漏れを0.99から0.999（時定数1000）まで変え、EXT-1600に近づくかを見る。これは、上の1が「振動子でなければできないこと」かを判断する基準になる。
3. 1と2のどちらでも、**読出しの遅れ（Bに応答するまでの時間）**と誤警報を合わせて測る。長い積分は、判断の遅れや状態の引きずりを生むはずである。

## 限界

- 探索。5回路、課題は1種類、Rは1素子、重みはオフラインのリッジ回帰。
- Rの選び方（`both` − 誤警報率、cとbの5×5格子）が、Rを「黙る」方に寄せた可能性がある。格子を細かくしても、EXT-R（0.55）を大きく越えることはないと考えられる。
- EXT-Rが一部の集団で0.5を下回ったのは、線形分類器のしきい値（訓練の両クラスの平均の中点）と、各履歴の割合の偏りの組合せによる。
