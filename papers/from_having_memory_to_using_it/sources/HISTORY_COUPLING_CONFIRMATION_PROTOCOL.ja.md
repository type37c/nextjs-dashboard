# 履歴寄与の確証実験：設計版 v1

2026-11-06。**設計文書。確証データは未取得。外部事前登録は未実施。**

この設計はpilotの結果を見て作成した。pilot自体を確証へ格上げしない。取得用ラッパー・解析コード・監査コードの実装と凍結は、この文書の後に行う。凍結前の変更は履歴を残す。

## 1. 主張と反証条件を先に置く

検証する主張は次に限定する。

> 既知の5回路、2つの準備候補、固定した時間スケジュール、同予算で訓練した特定の読み出しの下では、通常T7は、最初の準備境界以前のm成分の位相寄与を除くT7より、新しい入力群での全7回成功率が高い。

これは「履歴が常に資産」「知能にはこの単位が必要」という主張ではない。B2は位相速度の動作点も変える。内容の情報価値と動作点を完全に分離する実験ではない。

主効果を **Δ = 成功率(B0・再学習済み) − 成功率(B2単発・再学習済み)** とする。差はパーセントポイントで示す。

**最小重要差δは3ポイント**とする。これは科学的に既知の定数でもpilotから推定した閾値でもなく、小さな正差だけで強い実用的主張をしないための設計上の判断である。設計者がpilotの+7.03ポイントを知った上で選んだことを明記する。δによる分類と独立に、推定差・区間・全条件の生データを公開する。

|新評価群での主差の95%区間 [L,U]|結論と撤回|
|---|---|
|L > +3ポイント|定義した条件内で、最小重要差を上回る優位を支持|
|0 < L かつ L ≤ +3 ≤ U|正の差は支持されるが、3ポイントを上回る優位は未確立|
|0 < U < +3|3ポイント以上という実用的主張を撤回。区間が0をまたぐなら差の向きは未確定、L>0なら小さい正差|
|U ≤ 0|通常系の正の優位という今回の予測を支持せず撤回。U<0なら反対方向を支持|
|L ≤ 0 かつ U ≥ +3|精度不足などによる未決着。無効果や同等性を宣言しない|

境界U=+3は「3ポイントを上回る優位は未確立」とする。数値を丸める前に分類する。一般的な知能論を単一実験で撤回／証明するものではなく、撤回対象は上記の条件つき性能予測である。「ここで不支持なら知能は管理側にある」という逆向きの同定もしない。

## 2. 何を凍結し、何を新しくするか

出発点はpilotコミット `9bd3897`。上流の基板は `01d84b5a41cc8d521724bbaa0127601b086b9936`。

- 回路200–204、保持時間512・16384、準備候補、計算スケジュール、m参照値、介入位置をpilotから変更しない。
- **pilotの訓練群だけで学習したB0とB2単発の読み出しを、そのまま凍結して使う。** 同予算「再学習」は既に行った基板別較正を指す。確証評価中には再訓練しない。
- 訓練は条件ごとに8履歴群×4行×2保持時間×7判断。線形読み出し、特徴、正則化等はpilotと同じ。
- 5つの `refits.pkl` と元の較正ファイルのSHA256を `DESIGN_PARAMETERS.json` に記録した。使用するモデルはB0とB2_onceのみ。
- 取得前に2条件×5回路のモデルが揃うこと、モデルクラス・係数・固定候補が記録と一致することを検査する。正常なら評価ラベルを使った選び直しをしない。
- 新しくするのは評価用履歴群と入力乱数。pilotの訓練群・評価群、既存E7-D確証群は再利用しない。

したがって得られるのは、**この5回路とこの10個の学習済み方策に条件づけた、新しい入力群への性能**である。再学習を何度繰り返しても成立するというアルゴリズム全体の頑健性、新回路への一般化は別実験とする。

## 3. 取得条件

主実験は2基板×2方策。

|基板|再学習済み読み出し|固定準備|
|---|---|---|
|B0 通常|主比較|副比較|
|B2単発|主比較|副比較|

B2は最初の計算の判断窓終了後、準備の直前に `h=m−m_ref` を設定する。その後hをmと同じ係数で減衰させ、Pの位相計算だけに `m−h` を使う。再設定しない。m自体、境界時の位相、不応期、他ユニットは変更しない。境界後の入力はmに入り続ける。これはモデル内反実仮想であり、低コストな物理操作とは称さない。

固定準備はpilotの訓練で選ばれた候補を使う。B0・B2単発は5回路とも候補1であることを取得前にassertする。2条件間で候補を選び直さない。

B1、B2反復、B3、移植のC3は今回の確証には含めない。pilotの結果として残し、C3の介入強度や動作点対照の開発は別の探索実験とする。主比較を増やして結論を選択することを避ける。

## 4. 群数と停止条件

各回路 **128履歴群**、1群4行、2保持時間とする。1条件・1方策5,120チェーン、4セル計20,480チェーン。1チェーンの準備後7回を採点する。

推論上の群は5回路×128=640群。両保持時間、4行、4条件を群の中でまとめ、同じ乱数系列・初期履歴を条件間で対応させる。5,120チェーンを独立標本とみなさない。5回路は固定で、母集団から無作為抽出した回路とは扱わない。

群数はpilotの群間変動を用いて精度を見積もって選んだ。各回路の16群から推定した分散を使う正規近似では、128群／回路で主差の95%区間半幅は約1.14ポイント、分散が2倍なら約1.61ポイント。これはpilotに基づく計画近似であり、検出力・区間幅の保証ではない。計算値をパラメータJSONに保存した。

全予定群を取得して一度集計する。途中の成績を理由に停止・増数・条件変更しない。障害時は未完了群だけ同じ入力で再開し、完了済みの値は上書きしない。科学的結果を変えるバグなら、その取得を無効と明示して保存し、修正・再凍結・別cohortによる新しい実験として扱う。

## 5. 主解析

各チェーンの結果Yは、介入後の実入力7計算がすべて正答なら1、それ以外0。平均の単位は次の通り。

1. 各回路・履歴群で、4行×2保持時間のYを各条件で平均する。
2. 同じ群のB0再学習済み − B2単発再学習済みを差dとする。
3. 各回路の128群を等重みで平均し、5回路を等重みで平均した値をΔとする。
4. 回路ごとに128群を復元抽出し、保持時間・行・全条件を同時に動かす層別対応bootstrapを20,000回実施する。
5. Δのbootstrap分布の2.5・97.5パーセンタイルを95%区間とする。bootstrap用乱数は別固定seed。

主比較は一つ。bootstrapは固定回路・固定モデルに条件づけた近似推論であり、厳密な有限標本保証ではない。回路間・訓練乱数間の不確実性まで含む区間とは書かない。

回路ごとの主差、保持時間ごとの主差も必ず報告する。全5回路で正という条件を主判定へ後付けしない。平均が正でも負の回路があれば、その異質性を明記する。

## 6. 固定準備の逆転・A=1・失敗分解

以下は**事前に指定した副解析だが、確証の成功判定には使わない**。多重比較補正を伴う別の確証主張は行わず、推定値と記述的区間を示す。

- 固定準備での差 Δ_fixed = B0固定 − B2固定。
- 交互作用 I = Δ − Δ_fixed。これは `(B0再学習済み−B0固定) − (B2再学習済み−B2固定)` と同じ。対応群を保って区間を計算する。
- A=0とA=1別の主差、さらに `Δ_A1−Δ_A0` を示す。A=1だけを見て「難しい側に集中」と結論せず、差の差を併記する。正答率の天井効果や課題構成による差も限界とする。
- 直後1回の成功と、各段の成功。単発の局所効果と全7回の連鎖効果を区別する。
- 実次入力に対し「2候補とも失敗」と「成功候補があったが選ばなかった」を分ける。
- 4標準プローブの共同準備可能性に対する候補存在率・条件つき選択失敗率を別に報告する。実次入力を選択器に教えた成績と混同しない。

Iが正でも「記憶が資産になるためには必ず状態読出しが必要」とは証明しない。比較していない固定候補、別の制御器、別の基板にも一般化しない。共同プローブ目標と実入力の成績がずれる理由の同定には、目標自体を変える別実験が必要である。

## 7. データ分離と取得前チェック

新しいcohort seed候補は `9160600000 + device`、入力描画seed候補は `9160610000 + device`。bootstrap seedは `9160620000`。現時点では予約値であり、確証入力は生成していない。

取得前に既存のseed台帳・利用可能な実験記録と衝突がないか検査する。既知の衝突があれば新seedに置換し、変更理由と値を取得前に記録する。「seedが違う」だけで全履歴にわたる独立性が監査済みとは主張しない。

新入力を生成した時点で入力ファイルとSHA256を保存し、条件間で同じ入力を用いる。既存入力ファイルとの完全な行／群重複数を記録する。ただし離散課題では部分的に同じ値が自然に出るため、それを成績を見た後の除外理由にしない。履歴群の生成元が再利用されていた等の実装不備は、取得を止める理由にする。

凍結前に、pilotで既に実行した通常系一致、sham、κ遮断の交絡、介入境界、観測コピー再構成、実入力候補と実現結果の一致を確認する。新しい確証群をコード調整やドナー選択、候補・訓練目標の開発に使わない。
