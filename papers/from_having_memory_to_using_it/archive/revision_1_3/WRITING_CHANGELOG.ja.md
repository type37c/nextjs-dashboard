## 採用する解釈

新20回路では、指定した生成・較正・訓練の手順の下で通常−除去の平均正差と、通常−対応ドナーの正差を支持した。
固定準備の逆転も同じ新回路群で観測した。先行5回路の3ポイント最小効果基準未達は、そのまま未達として残す。

次の区別を本文と証拠マップの両方に明記した。

1. **周辺の大きさを揃えても差が残ることと、動作点の説明を全て除外することは別。** 位相などとの同時分布・状態適合性は未分離。
2. **ドナー−定数の差と、時間変動だけの利益は別。** ドナーの減衰と定数の持続では時間形・累積寄与も異なる。
3. **直後の小さい点推定と、直後の等価性は別。** 区間は約−2.98〜+2.94ポイントで、等価性検定は行っていない。軌道による媒介は仮説に留める。
4. **対応条件内の履歴差し替えと、厳密な残差化は別。** 同じA・現在入力を保存し、統計的な残差分解は実施していない。
5. **A=1の正差の再観測と、A=1だけに効果があることは別。** A=0の負差と保持条件の大小関係は一般化したと書かない。
