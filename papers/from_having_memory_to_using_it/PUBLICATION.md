Memory-Dependent Computation**, by Keisuke Ohtani. It is shared as a working
position-paper draft for discussion. It has not been presented here as a
peer-reviewed paper, accepted submission, or demonstration of general intelligence.

## Provenance and scope

The English manuscript, source parts, figures, bibliography, evidence snapshots
and original validation record are copied unchanged from research commit
`deaccf8874f54b0312a197d402a181258a1f02ae`. The research repository is
`type37c/oscillator-arithmetic`. Source identifiers are provenance, not a claim
that the full research checkout is publicly accessible.

The public edition updates the paper README, adds these publication notes, a
public inventory audit and the reviewed ZIP, and links the draft from the repository
README. Historical editorial text about future publication describes the state
when the source draft was written. This posting does not alter scientific claims,
minimum-effect decisions, experimental results or the manuscript body.

The included reports, saved summaries and acquisition-freeze records support
inspection of the claims. They are **not the complete executable reproduction
package** for the new history-contribution and donor experiments. In particular,
the full set of 2,251 experimental files and its Git history are not included.
OTB21 remains the independently runnable public study at the repository root.

`MANUSCRIPT_VALIDATION.json` records checks performed in the full research
checkout before posting. Its file hashes describe that source edition, including
the original README. `PUBLICATION_MANIFEST.json` instead describes this public
edition. Neither document is external replication or scientific peer review.

## Check the public copy

From the public repository root:

```bash
python papers/from_having_memory_to_using_it/audit_publication.py
python papers/from_having_memory_to_using_it/assemble_manuscript.py
```

The audit checks published file hashes, links used by the English manuscript,
and assembly consistency. It does not fit a model, acquire data, rerun dynamics,
or recalculate a statistical test. The original `validate_manuscript.py` needs the
full research checkout; use the public audit for this repository.

The ZIP is the unchanged reviewed bundle and retains its original source-stage
notes. It has its own internal manifest. No license grant is added by this posting;
the repository's existing licensing status applies.
